The circular RT mark is the repeating identity; the detailed Oxford/Mississippi hero artwork is reserved for large panels. Preserve aspect ratio. Do not recreate the mark using an unrelated font or copy tiny malformed lettering from concept van images.

Palette: obsidian #090B10, midnight navy #061A33, red #E10616, actual electric blue #244CFF, pure-white street/task lighting #FFFFFF. No cyan/teal accent substitution, amber/incandescent lamps, orange accents or grass inside completed themed areas.

Reproduction: run scripts/stage_grid_media.ps1 on Raven. It creates seven sign designs and stages them plus these originals in the discovered Planet Coaster 2 UserMedia folder. Each copied file is SHA-256 verified. The nine staged images have NOT all been placed on game billboards.
